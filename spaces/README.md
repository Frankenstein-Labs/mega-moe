# MEGA demo Space

Interactive demo for `Frankenstein-Labs/mega-small`, a small Mixture-of-Experts
language model trained from scratch as part of the MEGA reference project.

The model completes arithmetic, templated bilingual sentences and small code
snippets from its training corpus. It is a research artifact with no safety
tuning — see the banner in the app.

Source code: https://github.com/Frankenstein-Labs/mega-moe
