MEGA

A from-scratch Mixture-of-Experts language model — reference implementation

Research artifact. A small MoE model (16 routed + 2 shared experts, top-2) trained on CPU on a tiny structured corpus (arithmetic, templated fr/en sentences, small code snippets). It is not a general-purpose assistant and has no safety tuning.

from mega.hub.serialization import from_pretrained
from mega.tokenizer.tokenizer import MegaTokenizer
import torch

model = from_pretrained("Frankenstein-Labs/mega-small")
tok = MegaTokenizer.from_pretrained("Frankenstein-Labs/mega-small")

ids = [tok.bos_token_id, *tok.encode("17 + 16 =")]
out = model(torch.tensor([ids]))
print("17 + 16 =", tok.decode([int(out.logits[0, -1].argmax())]))
